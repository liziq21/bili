# 研究记录

本目录保存针对本项目的调查、选型、可行性研究与方案对比。它回答“我们为什么这样决定、依据是什么”，不替代可执行配置或 `AGENTS.md` 中的规则。

## 约定

- **每次研究都要留档。** 没有记录的结论不进入架构、依赖或产品决策；口头结论视为未完成。
- 文件名为 `<YYYY-MM-DD>-<slug>.md`，日期是研究发生或结论形成的日期，不是提交日期。
- 每份记录必须在正文开头写明：
  - **研究日期**：ISO 日期（`YYYY-MM-DD`）。
  - **研究状态**：`进行中` / `已完成` / `已废弃`。
  - **关联分支或 PR**（如有）。
  - **参考资料**：可访问的链接或仓库内路径；不得只写“网上资料”“官方文档”而不给地址。
- 记录至少包含：研究问题、结论、证据、方案与取舍、验证方式、未决问题。研究结论改变了代码或规则时，在同一次改动中链接到对应 PR/commit。
- 不要把凭据、Cookie、Token、账号数据或未脱敏的用户数据写进记录。
- 外部资料与仓库规则要分开标注；外部研究不自动构成本仓库的约束。
